Como funciona no JavaFX Desktop: O JavaFX possui seu próprio motor CSS. Você cria um arquivo style.css (utilizando propriedades prefixadas como -fx-background-color) e o vincula na Scene do JavaFX.
src/main/resources/css/style.css 
/* Arquivo CSS para Interface JavaFX Desktop */
.root {
    -fx-font-family: "Inter", "Segoe UI", sans-serif;
    -fx-background-color: #0f172a;
}

/* Card de KPI */
.kpi-card {
    -fx-background-color: #1e293b;
    -fx-background-radius: 12px;
    -fx-padding: 16px;
    -fx-effect: dropshadow(three-pass-box, rgba(0,0,0,0.3), 10, 0, 0, 4);
}

/* Botão Principal Estilizado */
.button-primary {
    -fx-background-color: linear-gradient(to right, #6366f1, #4f46e5);
    -fx-text-fill: white;
    -fx-font-weight: bold;
    -fx-background-radius: 8px;
    -fx-cursor: hand;
}

.button-primary:hover {
    -fx-background-color: #4338ca;
}

/* Tabela JavaFX (TableView) */
.table-view {
    -fx-background-color: transparent;
    -fx-border-color: #334155;
}
.table-view .column-header {
    -fx-background-color: #1e293b;
    -fx-text-fill: #94a3b8;
}
src/main/java/com/empresa/MainApp.java 
package com.empresa;

import javafx.application.Application;
import javafx.fxml.FXMLLoader;
import javafx.scene.Scene;
import javafx.stage.Stage;

public class MainApp extends Application {

    @Override
    public void start(Stage primaryStage) throws Exception {
        FXMLLoader loader = new FXMLLoader(getClass().getResource("/fxml/dashboard.fxml"));
        Scene scene = new Scene(loader.load(), 1100, 700);

        // LINK ESSENCIAL: Carrega o arquivo CSS na cena JavaFX
        String cssPath = getClass().getResource("/css/style.css").toExternalForm();
        scene.getStylesheets().add(cssPath);

        primaryStage.setTitle("JavaSLA Desk - Sistema Desktop");
        primaryStage.setScene(scene);
        primaryStage.show();
    }

    public static void main(String[] args) {
        launch(args);
    }
}
Como funciona no Spring Boot (Web): O Spring Boot serve o CSS estático na pasta src/main/resources/static/css e renderiza dados dinâmicos do Java na View HTML com Thymeleaf.
ChamadoController.java 
@Controller
@RequestMapping("/chamados")
public class ChamadoController {

    @Autowired
    private SlaService slaService;

    @GetMapping
    public String listarChamados(Model model) {
        List<Chamado> lista = slaService.buscarTodos();
        
        // Envia a lista tratada e calculada para a tela HTML
        model.addAttribute("chamados", lista);
        model.addAttribute("totalHorasSLA", slaService.calcularTotal());
        
        return "dashboard"; // Renderiza o arquivo dashboard.html
    }
}
templates/dashboard.html (Thymeleaf + CSS) 
<!DOCTYPE html>
<html xmlns:th="http://www.thymeleaf.org">
<head>
    <!-- Vincula o CSS estático servido pelo Spring Boot -->
    <link rel="stylesheet" th:href="@{/css/style.css}" />
</head>
<body class="bg-slate-950 text-white">
    <tr th:each="chamado : ${chamados}" class="border-b">
        <td th:text="${chamado.id}">#101</td>
        <td th:text="${chamado.titulo}">Erro de Conexão</td>
        <td>
            <!-- Aplica classe CSS dinâmica conforme o status Java -->
            <span th:class="${chamado.atrasado} ? 'badge-danger' : 'badge-success'"
                  th:text="${chamado.horasSlaFormatted}">04:30</span>
        </td>
    </tr>
</body>
</html>
